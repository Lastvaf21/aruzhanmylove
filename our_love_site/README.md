# Наша маленькая вселенная ❤️

Романтический адаптивный сайт-открытка. Работает на обычном HTML, CSS и JavaScript — без установки программ и библиотек.

## Как добавить свои фотографии

Открой папку `images` и замени картинки-заглушки своими файлами, сохранив имена:

- `photo-1.jpg` ... `photo-6.jpg` — ваши совместные фотографии.
- `chat-1.jpg` ... `chat-4.jpg` — скриншоты переписок.

Можно использовать `.jpg`, `.png` или `.webp`, но тогда поменяй расширение в `index.html` тоже. Лучше заранее обрезать фотографии примерно под квадрат, а скриншоты чатов оставить вертикальными.

В архиве есть пустые файлы-заглушки с нужными именами. Просто замени их настоящими изображениями.

## Как добавить мелодию

Положи свой аудиофайл в папку `music` и назови его `our-song.mp3`.
Если у тебя файл с другим названием или форматом, измени путь в `index.html` в строке с `<audio>`.

Важно: музыка не стартует сама при открытии страницы — браузеры обычно запрещают автоматическое воспроизведение со звуком. Девушка нажмёт на кнопку с ноткой, и мелодия начнёт играть.

## Как изменить текст

Открой `index.html` в VS Code и найди блоки:
- `Моя любимая` — надпись на первом экране.
- `Любимая, я хочу...` — основное поздравление.
- `Мой любимый момент` и другие подписи — подписи под фотографиями.
- `Я выбираю тебя` — финальная часть.

Меняй текст прямо между HTML-тегами, не удаляя сами теги.

## Как выложить на GitHub Pages

1. Создай аккаунт на https://github.com, если его ещё нет.
2. Нажми **New repository** и назови репозиторий, например `our-love`.
3. Выбери **Public**, затем **Create repository**.
4. Загрузи в репозиторий все файлы и папки проекта: `index.html`, `style.css`, `script.js`, `images`, `music`.
5. Открой **Settings → Pages**.
6. В разделе **Build and deployment** выбери **Deploy from a branch**.
7. В Branch выбери **main** и папку **/(root)**, затем нажми **Save**.
8. Подожди немного. В разделе Pages появится ссылка вида `https://ТВОЙ-ЛОГИН.github.io/our-love/`.
9. Открой ссылку на телефоне и проверь фотографии и музыку.

## Небольшие советы

- Не загружай личные фотографии, если не хочешь, чтобы их мог увидеть любой человек: публичный GitHub Pages-сайт доступен всем, у кого есть ссылка, а иногда и поисковым системам.
- Для быстрой загрузки сайта сжимай фото до примерно 1–2 МБ каждое.
- Если GitHub не показывает сайт сразу, подожди пару минут и обнови страницу.
